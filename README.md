# Мой дом · Владивосток

Интерактивная карта города, обращения жителей, квитанции и аналитика.

## Возможности

- Город → район → ЖК → паспорт дома, поиск адресов, прямые ссылки и избранные дома.
- Обращения с фото, поддержка и голосование о решении проблемы.
- Разбор текстовых PDF и текста квитанций, сравнение начислений, работы и отключения.
- Регистрация и кабинет: дома, обращения, квитанции, счётчики, соседи, настройки.
- Связанные с картой графики: категории и статусы обращений, состояние домов, квитанции по месяцам, рейтинг районов.
- MapLibre с окрашенными контурами зданий и объёмным режимом без обязательного ключа; Leaflet — резерв при недоступности WebGL.

## Запуск Node.js

Node.js 24 и npm. Для локального запуска исходного сервера:

```sh
npm ci
cp .env.example .env
node -e "require('fs').closeSync(require('fs').openSync('prisma/dev.db','a'))"
npx prisma db push
npm run seed
npm run dev:node
```

Откройте http://localhost:3000. `npm run build:node` собирает Node-версию; затем `npx next start`. Повторный `seed` не меняет уже заполненную базу.

## Sites / Workers

`npm run build` собирает Vinext Worker в `dist/server/index.js`, браузерные ресурсы — в `dist/client`. `npm run db:local` применяет начальную SQL-схему к **новой** локальной D1; повторно эту команду не запускайте. `npm run dev` запускает разработку с D1/R2, `npm start` — собранный Worker. Оба режима используют `.wrangler/state`.

Публикация выполняется через Sites с конфигурацией `.openai/hosting.json`. Рабочие данные — D1, фото — R2. Официальный адаптер Prisma D1 сохраняет существующие контракты запросов; SQL-миграции лежат в `drizzle/`. Голосование использует атомарный D1 batch вместо неподдерживаемой интерактивной транзакции. Начальный набор `db/demo-seed.json` содержит только поставляемые демоданные, без пользователей, сессий и кабинетов. Загрузка идемпотентна и не заменяет существующие записи. Новые миграции добавляйте отдельными файлами; применённые не редактируйте.

Для размещения необходимо применить схему D1 до первого запроса. Локальная SQLite и размещённая D1 — разные базы. Реальные пользовательские данные между ними автоматически не переносятся.

Браузерные тесты используют `E2E_BASE_URL`, если указан, либо управляемый предпросмотр. `PLAYWRIGHT_EXECUTABLE_PATH` позволяет выбрать установленный Chromium.

## Данные и ограничения

Адреса и здания: © участники OpenStreetMap, ODbL. Управляющие компании, обращения и квитанции — демонстрационные.

Индекс состояния — расчёт по возрасту и зарегистрированным обращениям, а не техническое обследование. Дома без достаточных сведений исключены из рейтинга; охват показан рядом с графиками. Фильтр периода применяется к датам обращений и месяцам квитанций по часовому поясу Владивостока. Возраст дома рассчитывается на текущую дату. Среднее начисление считается по домам с квитанциями в конкретном месяце, поэтому состав выборки может различаться.

Госуслуги и отправка обращений в ведомства — демонстрационные. Разбор документов работает по правилам, без внешних моделей; сканы без текстового слоя не распознаются.

## GitHub и приватные файлы

Публичный репозиторий содержит код, миграции и безопасные демоданные. `.env`, базы, фото пользователей, резервные копии и служебные каталоги исключены через `.gitignore`. Не помещайте секреты в `NEXT_PUBLIC_*`: такие значения доступны браузеру. Каждый завершённый этап сохраняется отдельным коммитом без перезаписи истории. GitHub Actions проверяет типы, тесты и Worker-сборку.

## Карта Atlas (обновление интерфейса)

Основной экран — карта с компактной верхней панелью; подробная аналитика открывается по кнопке. Интерфейс использует нейтральную чёрно-бело-серую палитру. Цвет зданий показывает выбранный индекс: инфраструктура — от серо-лилового до фиолетового, надёжность сетей — от красного до бирюзового. Без сведений контур остаётся серым.

Карта подгружает только здания в видимой области.

MapLibre отображает реальные контуры в 2D и 3D, часть высот оценочная. Дороги и береговая линия © OpenStreetMap; дополнительный рельеф — открытые Terrarium tiles (Mapzen / AWS). При недоступности WebGL включается Leaflet с теми же окрашенными контурами. Контуры, дороги, вода и показатели хранятся вместе с приложением; внешний интернет нужен только для дополнительного рельефа. Старые демонстрационные обращения и квитанции доступны отдельно внутри подробной аналитики.

Служебный модуль MapLibre копируется из установленной зависимости скриптом `prepare-map-assets.mjs` до запуска и сборки. Береговая линия и дороги также сохранены в `base.geojson`: основная карта не зависит от внешнего растрового сервиса. Генерируемый `public/vendor/` не хранится в Git.
